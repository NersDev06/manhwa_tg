## О проекте manhwa-telegram

Telegram-бот для автоматической публикации манхвы в каналы с веб-панелью управления.

### Технологии
- Python 3.13+ (воркер публикаций)
- Next.js 14+ (веб-интерфейс FRAME)
- MongoDB Atlas (очередь и метаданные)
- Telegram Bot API
- Vercel (деплой фронтенда)
- Heroku (опционально для воркера)
