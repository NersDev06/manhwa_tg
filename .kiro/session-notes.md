### Технические детали

**Структура проекта:**
- Python backend: manhwa/ (воркер публикаций)
- Next.js frontend: dashboard/ (админка FRAME)
- MongoDB для очереди и метаданных
- Telegram Bot API для публикаций

**Архитектура бота:**
- Источники: MangaShi → WaManga → MangaBuff → ReManga (fallback цепочка)
- PDF генерация с сохранением оригинальных пропорций
- Очередь публикаций с повторными попытками
- Превью глав перед публикацией
