# Восстановление публикаций и FRAME — 19 октября 2026

Рабочая панель: https://manhwa-frame.vercel.app. Развёрнута Vercel CLI в аккаунте
nersfullstack-1846, проект manhwa-frame; подключение GitHub не требуется.
Пароль хранится в dashboard/.env.local и production Secret Vercel.

## Что сломалось

MangaShi возвращал HTTP 403. Шесть попыток отправки PDF завершились без
однозначного ответа Telegram, после подтверждённого превью. Защита от дублей
поставила их в uncertain и остановила дальнейшие главы соответствующего канала.
Ещё две главы 2 остановились на CalledProcessError конвертера. Старый журнал
сохранял только имя исключения, поэтому точная причина этих двух старых падений
не восстановлена. Обе главы успешно собраны и отправлены из WaManga.

Все шесть спорных отправок проверены через историю Telegram: после последних
превью PDF отсутствовал. Восстановлены только недостающие файлы с сохранением
preview_receipt. Все восемь восстановленных заданий получили status=sent и
подтверждения Telegram. На этом снимке 62 главы sent из 1709, 1647 pending,
failed/uncertain=0. Очередь продолжает работать, числа изменяются.

## Исправления

- Резерв WaManga для всех восьми тайтлов. Существующие задания не пересоздаются;
  сохраняются URL/ID/том/номер, в том числе при возврате MangaShi. Неоднозначные
  совпадения не угадываются. При недоступности основного источника действует пауза
  его проверок, остальные запросы идут к проверенному резерву.
- Готовые PDF и порядок частей хранятся на локальном диске между попытками.
  Подтверждённые превью и части не отправляются снова. Кэш удаляется после успеха.
- Обычная глава снова отправляется одним PDF. Части нужны только для больших
  файлов: запас до лимита Bot API 50 MB, потолок файла 49 MB. Первые несколько
  восстановленных глав были отправлены частями с временным уменьшенным порогом;
  эти подтверждённые публикации не удалялись и повторно не публиковались.
- Потоковая загрузка HTTPX с отдельными connect/read/write timeout; write=600 с.
  Соединение, которое ещё не установилось, можно повторять. Обрыв после начала
  передачи по-прежнему требует проверки канала: Telegram не даёт ключ идемпотентности.
- Передаваемые байты и этапы обработки доступны в панели. Из журнала HTTPX
  исключена строка запроса, содержащая секретный Bot API URL.
- Конвертер сохраняет безопасную конечную причину ошибки вместо непрозрачного
  CalledProcessError. Ограничения размера входных изображений сохранены.
- В именах файлов сохраняется номер главы даже при длинном названии тайтла.
- launchd теперь автоматически загружает сервис после входа в macOS. Секретов в
  plist нет. `scripts/local_worker.py stop` останавливает сервис и снимает автозапуск.

## Панель

Тёмная тема по умолчанию, переключатель сохраняет выбор. Показаны очередь с
фильтрами/пагинацией, текущая глава, подготовленные изображения, переданные байты,
подтверждённые отправки, ошибки, публикации за сутки, подписчики каждого канала,
подключение комментариев и актуальность метрик. Сумма подписчиков не означает
уникальных людей. UI опрашивает состояние каждые 15 секунд, Telegram-метрики
обновляет локальный воркер раз в 5 минут. Lease определяет состояние online.

Вход защищён подписанной HttpOnly/Secure/SameSite-сессией. API не возвращает
MongoDB URI, токен Telegram или секреты панели. Есть ограничение попыток входа
и проверка Origin. Серверные секреты заданы только для production.

Проверки: 39 Python-тестов, TypeScript и production-сборка Next.js; настоящий вход,
API, фильтры, пагинация, выход, отказ без авторизации и при чужом Origin;
визуально проверены desktop и мобильный макет. Снимки — output/dashboard-*.png.

## Текущие ограничения

В резерве WaManga отсутствуют три специальных выпуска: варвар 80.5, Петер 104.1 и 104.2.
Два спецвыпуска Петера дополнительно проверены в MangaBuff (63 и 11 страниц).
В очереди сохранены все номера. Сейчас без проверенного резерва остаётся только
варвар 80.5: если MangaShi не восстановится к его обработке, канал варвара
остановится на этом спецвыпуске; остальные продолжат работу. Это отмечено в панели.

Исторические просмотры и количество комментариев Bot API не предоставляет.
Панель показывает состояние обсуждений вместо фиктивных чисел.

Звёздные реакции в доступном Telegram Web не настроены: нужного переключателя
нет. Обычные реакции доступны, Stars не покупались и не отправлялись.

Heroku worker остаётся выключен. Vercel обслуживает только панель. Публикации
работают на Mac: выключение компьютера/закрытая крышка прерывают работу.


## Дополнительная проверка качества

У WaManga для Петера обнаружены изображения шириной около 100 пикселей.
Первоначально отправленные главы 2 и 3 заменены в тех же сообщениях на полноценные
PDF из MangaBuff: 13 страниц, 16.1 и 14.8 MB. Обновлены file_id и статистика
заданий; номера сообщений сохранены. Превью главы 3 также исправлено на полный
фрагмент. У остальных семи источников проверены первая/последняя страницы: ширина
609–802 px. Дальше конвертер отклоняет явно уменьшенные длинные полосы до публикации.

По последней просьбе владельца превью сохраняет пропорции выбранного полного
фрагмента; квадратная центральная обрезка удалена. Белые края срезаются, изображение
не увеличивается. Пустые чёрные промежутки между панелями также распознаются.


Временные ошибки источника переоткрываются после следующей успешной проверки
каталога для доступных номеров. Это не применяется к неопределённым отправкам
Telegram. Явный rate limit 429 и таймаут до соединения остаются повторяемыми
после пятой попытки, с ограниченной экспоненциальной паузой.
