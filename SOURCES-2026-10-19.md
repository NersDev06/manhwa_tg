# Резервные источники и панель — 19 октября 2026

Панель: https://manhwa-frame.vercel.app

## Что завершено

- Для восьми настроенных произведений проверены каталоги и изображения MangaBuff; для семи — ReManga. Подключены конкретные произведения и ветки перевода, автоматического подбора похожих названий нет.
- Основной MangaShi сейчас возвращает HTTP 403. Система использует доступные резервы без обхода защиты. Для «Убийцы Петера» приоритет у MangaBuff, затем ReManga; изображения WaManga для него отключены из-за низкого разрешения.
- При сбое изображения, декодирования или проверки читаемости следующая попытка скачивает **всю главу** из следующего источника. Страницы разных сайтов не смешиваются.
- Публичное продолжение каталога MangaBuff загружается полностью, включая главы после первых 100. Платные и неопубликованные главы ReManga не используются.
- У ReManga исходная страница состоит из нескольких JPEG-фрагментов. Они собраны на одном непрерывном полотне PDF в исходном порядке, включая хвосты высотой 2 пикселя. JPEG не перекодируется; огромный общий bitmap не создаётся.
- Превью сохраняет пропорции выбранного кадра и убирает белые края. Крошечные фрагменты-разделители не выбираются как превью. Обычная глава отправляется одним PDF; большие — частями до 49 МБ.
- Уникальный индекс `chapter_identity` по подписке, тому и числовому номеру главы действует в настоящей MongoDB. Изменение адреса или источника не создаёт новую запись.
- Существующие ID заданий, статусы, превью и Telegram-квитанции сохраняются. Неизвестные старые главы ниже уже опубликованной позиции не отправляются автоматически задним числом.
- Если после частичной отправки потерян локальный PDF, сборка из другого источника запрещена: иначе мог бы измениться состав частей.
- Неоднозначная доставка Telegram по-прежнему требует проверки; слепого автоматического повтора нет.

## Новое в панели

- Раздел **«Источники»**: состояние каталога, количество глав, время проверки, HTTP-сбой, текущий источник и отсутствующие дополнительные главы. Пометка «доступен» относится к каталогу и не гарантирует наличие каждой главы.
- Глобальная пауза и пауза отдельного канала. Пауза не прерывает уже выполняющуюся главу; очередь, квитанции и подготовленные PDF сохраняются. Во время глобальной паузы новые публикации не начинаются, мониторинг продолжается.
- Журнал публикаций, ошибок, запусков, остановок и изменений настроек. MongoDB удаляет записи по TTL через 30 дней; личные переписки, токены и содержимое глав в журнал не записываются.
- Управляющий API требует действующую сессию, собственный Origin и проверенные параметры. Токен Telegram остаётся только у локального воркера.
- Все показатели берутся из базы и Bot API. Число комментариев и просмотров Bot API не предоставляет: панель показывает подключение обсуждений, а не выдуманные числа.

## Режим работы и ограничения

Воркер работает на компьютере через launchd; Heroku выключен. После входа в macOS сервис стартует автоматически. При выключении, закрытой крышке или отсутствии сети непрерывная публикация не гарантируется. Панель Vercel доступна отдельно от воркера и показывает его отсутствие связи.

```sh
.venv/bin/python scripts/local_worker.py status
.venv/bin/python scripts/local_worker.py stop
.venv/bin/python scripts/local_worker.py start
```

Текущий режим без дневного ограничения, одна глава за раз с паузой 60 секунд. Параметр `DAILY_CHAPTER_LIMIT` позволяет установить дневное ограничение. Архив не объявляется полностью загруженным: фактический прогресс виден в панели.

Обсуждения подключены к восьми каналам в предыдущем обновлении. Платные реакции Stars ранее не были включены: в доступном веб-интерфейсе не было нужного переключателя. В этом обновлении личные Telegram-чаты не открывались, настройки платных реакций не менялись.
