# Расширение сети каналов — 18 октября 2026

1. `source.py`: реальные названия, синонимы, оригинальное название, статус и обложка MangaShi; подтверждение соответствия восьми тайтлов.
2. `seo.py`: транслитерация, кандидаты адреса, название, описание до 250 символов, подписи с хештегами и экранированием HTML.
3. `store.py`, `worker.py`, `__main__.py`: 0 означает отсутствие суточного лимита; один процесс, блокировка MongoDB, очерёдность, пауза между главами и обработка 429 сохраняются.
4. `promotions.py`: после окончания первичного архива сохранить счётчик; дальше один пост с кнопками после каждых трёх новых глав. Во время накопившегося обновления дождаться конца очереди данного тайтла. Не отправлять старые рекламные посты пачкой. Не повторять отправку с неизвестным результатом.
5. `telegram.py`, `channel_setup.py`: оформление, обложка, тихий закреплённый навигатор с полными синонимами и прямой ссылкой на первую опубликованную главу. Сохранить ID сообщений для повторного запуска без дублей.
6. `preview.py`: фрагмент средней страницы, поиск белых разделителей, квадратный кадр; тяжёлое декодирование в отдельном процессе. Проверка только в test, производство включать отдельно.
7. Через аккаунт владельца: создание и публичный адрес шести каналов, ограничение сохранения, минимальные права бота для публикации и оформления. Bot API не создаёт каналы и не назначает им username. Звёздные реакции проверять в доступном интерфейсе владельца.
8. `COMPETITION.md`: проверяемые примеры конкурентов со ссылками; отделить прямые PDF-архивы от агрегаторов и озвучки, не выдавать старую индексацию за сегодняшнюю статистику.
9. Проверки очереди, неопределённой доставки, ограничений SEO и сохранения архива; контролируемый деплой Heroku, проверка фактических сообщений.

Обещания ранжирования, публикации «первыми» и защиты от бана не даются. PDF собирается нами из чужих изображений; упаковка не передаёт права на изображения. Резервный источник требует проверки соответствия тайтла, тома, главы, языка и перевода, а не автоматического выбора по похожему названию.
