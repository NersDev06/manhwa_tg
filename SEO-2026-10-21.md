Закрытая панель издателя: https://manhwa-frame.vercel.app/

## Для читателей

Созданы каталог восьми произведений, отдельная страница каждой манхвы и инструкция
по чтению. В каталоге работают поиск по русским, английским и альтернативным
названиям, фильтры жанров и сортировка. Оформление использует объёмные обложки,
светлую бумагу и тёмно-зелёную палитру; тёмная тема панели издателя сохранена.

Оглавления содержат 1710 подтверждённо опубликованных глав с прямыми ссылками
на существующие Telegram-посты. Дробные номера и части больших PDF сохранены.
Список разбит на группы по 50 глав, есть поиск номера, начало и последняя глава.
Последняя открытая через сайт глава запоминается только в браузере читателя.
Карточки связаны рекомендациями похожих произведений.

Публичные страницы берут только разрешённые поля опубликованных глав. Кеш
обновляется с интервалом 300 секунд. При недоступности MongoDB используется
проверенный публичный снимок ссылок. Появление новых глав проверяет облачный
издатель раз в час; это не означает, что автор выпускает главу каждый час.

## Поисковые системы

Для страниц заданы собственные заголовки, описания, канонические URL, карточки
Open Graph и разметка JSON-LD. Превью ссылок генерируются с поддержкой кириллицы.
Обложки размещены на том же домене. `robots.txt` указывает карту сайта;
`sitemap.xml` содержит каталог, инструкцию и восемь страниц произведений.
Корень с панелью издателя помечен `noindex`; API требуют авторизацию.

В Google Search Console подтверждено владение URL-префиксом сайта через HTML-файл.
Карта сайта **успешно обработана Google, обнаружено 10 страниц**. Файл
`dashboard/public/google9fd914ea4680b731.html` нужно сохранять при следующих деплоях.

На момент проверки каталог ещё не находился в индексе. Дополнительный ручной
запрос индексирования Google отклонил с сообщением «Квота превышена»; запрос
не принят. Карта сайта при этом обработана успешно. Сроки появления страниц
и позиции в выдаче не гарантируются. Платное продвижение и покупки не выполнялись.

## Надёжность и проверка

При проверке перезапуска Heroku обнаружена гонка: новый процесс мог стартовать,
пока прежний ещё держит блокировку. Добавлено ожидание до 120 секунд без захвата
чужой действующей блокировки; остановка во время ожидания безопасна. Отсутствие
заданий теперь явно показывает состояние `idle`, а не старое `starting`/`paused`.

Пройдены 74 Python-теста, включая ожидание освобождения блокировки, защиту живого
владельца и остановку во время ожидания. После изменения состояния ожидания
повторно пройдены 16 тестов воркера. Сборка Next.js и проверка опубликованного
сайта прошли: восемь страниц, 1710 ссылок, 10 URL в sitemap, обложки, JSON-LD,
канонические адреса, PNG-превью и 404 неизвестного произведения.

Вход в живую панель, чтение состояния и выход проверены. Без входа API отвечают
401; авторизованный ответ имеет `Cache-Control: private, no-store`.
Название, описание и ID закрепа всех восьми каналов подтверждены через Bot API.

Сохранены снимки в `output/seo/`: `catalog-desktop.png`, `google-verified.png`,
`google-sitemap-processed.png` и `google-index-quota.png`.
Резервная копия оформления до изменения — `tmp/presentation-backup.json`.

Один Heroku Basic остаётся единственным издателем; локальный воркер не запускался.
Новые платные ресурсы не добавлялись. Интервалы: опрос 3600 секунд, пауза между
публикациями 10 секунд. Рекомендации после трёх новых опубликованных глав сохранены.

## Обслуживание

Для нового произведения нужно добавить его редакционные данные и публичные
настройки в `config/editorial.json` и `dashboard/data/titles.json`, затем обновить
публичный снимок: `PYTHONPATH=. .venv/bin/python scripts/export_public_catalog.py`.
Секретов и Telegram file_id в снимке нет.

Проверка сайта без изменений: `.venv/bin/python scripts/verify_catalog.py --base https://manhwa-frame.vercel.app`.
Сценарий `scripts/apply_catalog_presentation.py` без `--apply` показывает план;
флаг `--apply` меняет оформление каналов на месте. Он не отправляет главы заново.

Редакционные описания написаны самостоятельно по официальным страницам WEBTOON
и Tapas; ссылки на них указаны на страницах соответствующих произведений.
