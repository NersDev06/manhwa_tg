Управление: `.venv/bin/python scripts/local_worker.py start|status|stop`.
Лог: `tmp/local-worker/worker.log`. Сервис работает независимо от этого чата
в текущем пользовательском сеансе macOS, перезапускается при сбое и использует
caffeinate -i для предотвращения обычного засыпания от бездействия.

публикация может остановиться. После перезагрузки запустить сервис командой start.

## Что работает

- Суточный лимит снят: DAILY_CHAPTER_LIMIT=0. Сохранились последовательная очередь,
  справедливое чередование тайтлов и пауза 60 секунд между главами.
- Перед каждой новой главой отправляется квадратное превью из средней страницы,
  затем полный PDF. Изображение для превью повторно с сайта не скачивается.
  Старые опубликованные главы задним числом не дублируются.
- Отдельно сохраняются ID превью и PDF-частей. Повтор обработки после подтверждённого
  превью не отправляет его снова; неизвестная доставка требует ручной проверки.
- Названия, описания, синонимы, обложки и подписи с хештегами формируются из метаданных.
  Неподтверждённых обещаний «самые первые главы» нет. Английское название «Регрессора»
  исправлено после проверки разделителя альтернативных названий.
- Навигатор автоматически получает прямую ссылку на первую реально опубликованную
  главу. Для рыцаря первой считается опубликованный пролог 0.
- Рекомендации подавлены до завершения архива каждого канала. После этого — один
  пост после каждых трёх новых глав, в конце очереди данного тайтла, с кнопками
  остальных активных каналов. Факт отправки и счётчик сохраняются в MongoDB.
- При Telegram 429 сохраняется общая пауза. Один MongoDB lease не допускает двух
  воркеров. Во время последнего обновления воркер остановлен между главами.

Дополнительный owner_username.py реализован и проверен тестами: кандидаты,
